## 列表页 list(1).html 翻页组件修复
- 列表页正文+翻页改用 CMS 组件 `tplpagedown.jsp`（begineditable name="翻页标题列表" viewid 204253），不再硬编码 `<ul>`+页码。
- 坑：CMS 翻页输出用的是 `pb_sys_common pb_sys_normal pb_sys_style1` 类名 + `includePageBarCss` 注入样式，并非静态 HTML 的 `.pagination`；之前只写 `.pagination` 的 CSS 导致翻页"格式全掉"（尤其关掉系统自带样式后完全没样式）。
- 修复：`list(1).html` 的 `<style>` 里把翻页样式改写，同时兼容 `.pagination` 与 `.pb_sys_common.pb_sys_normal.pb_sys_style1` 两套容器，并用 `!important` 盖掉 CMS 自带边框；另加 `ul{display:contents}` / `li{inline-flex}` 兼容 CMS 可能用 `<ul><li>` 包裹页码的情况。
- 注意：当前页高亮依赖 CMS 给当前页/禁用页加 `active/current/disabled/nolink` 之类 class；若高亮不生效，需照实际渲染 class 补一条规则。
- CMS 分页样式对话框可填 `<div class="pagination">${cssPageBar}</div>`（关掉系统自带样式）或保留默认 pb_sys 模板 + 用本文件 CSS 覆盖（两路都已被兼容）。
